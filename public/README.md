
# CarePoint+ - Doctor Appointment Booking System

## Project Description
CarePoint+ is a web-based Doctor Appointment Booking System that allows patients to view doctors, book appointments and manage their bookings.

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- SQLite

## Features
- Doctor listing
- Patient information collection
- Appointment booking
- Appointment cancellation
- Database storage
- Admin dashboard
- Appointment search
- Patient and doctor statistics

## Installation

1. Clone the repository.
2. Open the project folder.
3. Install dependencies:

   npm install

4. Start the server:

   npm start

5. Open in browser:

   http://localhost:3000

## Admin Dashboard

http://localhost:3000/admin.html
